Privacy Policy

Last updated: October 17, 2026

About the application

JobSniperRU Backup is a private utility used by its owner to store encrypted application backups in Google Drive.

Google Drive access

The application uses the Google Drive API with the drive.file permission to upload and manage files created by the application.

Data storage and security

Backup archives are encrypted before being uploaded to Google Drive. OAuth credentials are stored on the owner's private server and are not published.

Data sharing

The application does not sell user data or share it for advertising. Google Drive is used as the backup storage provider.

Data retention and deletion

Backup files are retained until the owner deletes them. The owner can delete backup files from Google Drive and revoke application access through Google Account settings.

Contact

For inquiries, contact the application owner via GitHub.
